openHC Controller

This driver brings an openHC box into the project as a controller: its on-screen navigator, its audio outputs (as Control4 digital audio zones), and its IO (serial, IR, relays, contacts). The openHC Setup tab is the box's own web UI for its settings, display, audio and updates.

Setup

  1. Address. If you added this driver from Composer's discovered devices, it already has the box's address. Otherwise identify the driver's network connection on the Connections → Network tab, as for any IP device.
  2. On-screen navigator. Bind HDMI (Audio/Video) to the TV's input, and the Onscreen Navigator to the room, so the room's C4/menu button opens the UI on that TV.
  3. Audio. Each Digital Audio Client binds to Digital Media by itself. Bind the matching Audio Output to the amplifier or speaker the box feeds; the room then plays Control4 digital audio (ShairBridge, TuneIn, My Music) through the box.
  4. IO. Bind the relays, contacts, IR outputs and serial ports the box has, like a controller's own. Connections the box doesn't have are simply left unbound.

Status (Properties tab)

  • Link Status: the on-screen navigator's connection to the box.
  • Token Status: the project token handed to the box so its UI shows this project. Send Project Token = No keeps it on this controller.
  • IO Status: the connection to the box's IO server. If iod has a token set, put it in IO Token.
  • Last IO Command: what Director last sent an IO connection.
  • openHC Web UI: the Setup tab's page as a link, once the driver knows the address.
