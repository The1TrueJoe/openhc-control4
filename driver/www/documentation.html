openHC Controller

Puts an openHC controller back in the project: its on-screen navigator on the HDMI/component output, and its relays, contacts, IR outputs and serial ports.

  1. Target IP Address: the openHC controller.
  2. Bind HDMI (Audio/Video) to the TV input; the Onscreen Navigator binds itself.
  3. Bind the IO connections the box has (relays, contacts, IR, serial) like a controller's own.

Send Project Token = Yes mints a Director REST token here and hands it to the box so its UI shows this project. IO Token is iod's IOD_TOKEN, if set.

Status: Link Status (navigator), Token Status, IO Status. Last IO Command shows what Director sent an IO connection.
