openHC Controller

Setup

  1. Address. If you added this driver from Composer's discovered devices, it already has the box's address. Otherwise identify the openHC Controller connection on the Connections → Network tab, as for any IP device.
  2. On-screen navigator. Bind HDMI (Audio/Video) to the TV's input. The Onscreen Navigator binds itself, so the room's C4/menu button opens the UI on that TV.
  3. IO. Bind the relays, contacts, IR outputs and serial ports the box has, like a controller's own. Connections the box doesn't have are simply left unbound.

Put the box's address above to see its own dashboard here: settings, IO, the display, updates. The openHC Web UI property is the same page as a link, and shows the address once the driver knows it.

Status (Properties tab)

  • Link Status: the on-screen navigator's connection to the box.
  • Token Status: the project token handed to the box so its UI shows this project. Send Project Token = No keeps it on this controller.
  • IO Status: the connection to the box's IO server. If iod has a token set, put it in IO Token.
  • Last IO Command: what Director last sent an IO connection.
